# Hand Crush Web

一个面向手机浏览器的手势交互 H5 挑战试玩项目：
用户打开网页授权相机，把手对准屏幕中的目标，**通过握拳动作触发“抓爆”效果**，并在 30 秒内尽量取得更高成绩。

当前版本定位：
- 可直接部署到 HTTPS 公网地址
- 可分享给手机用户试玩
- 支持基础 PWA 安装体验
- 内置启动引导、权限失败提示、移动端适配
- 自带挑战倒计时、击碎数、连击与结算

---

## 在线试玩目标

项目目标不是本地 demo，而是：

> 生成一个手机用户直接点开就能玩的公网链接。

因此当前版本重点做了：
- HTTPS 部署准备
- 移动端浏览器兼容提示
- 首屏引导
- 相机权限失败提示
- 挑战 HUD（倒计时 / 击碎数 / 连击）
- 回合结算与再来一局
- 生产环境隐藏调试面板

## 本地开发

```bash
npm install
npm run dev -- --host
```

然后打开：
- 电脑：`http://localhost:5173`
- 手机：终端输出的局域网地址

> 注意：相机功能在手机上通常要求 HTTPS；局域网开发阶段不同浏览器策略可能不同。

---

## 生产构建

```bash
npm run build
npm run preview -- --host
```

- Vercel

- [DEPLOY.md](./DEPLOY.md)

## 推荐试玩环境

### iPhone
- 优先使用 Safari
- 必须 HTTPS
- 振动反馈可能受限，这是浏览器限制

### Android
- 推荐 Chrome
- 相机与振动支持更稳定

## 当前能力

- 单手识别
- 握拳进入 `FIST_HOLD`
- 命中目标后触发抓爆
- 粒子爆散 / 冲击音 / 振动反馈
- 自动性能档位调整
- 启动失败 / 权限失败提示
- 可安装到主屏幕（依赖浏览器支持）
- 挑战 HUD：倒计时 / 击碎数 / 连击
- 回合结算：本局击碎数 / 最高连击 / 再来一局
